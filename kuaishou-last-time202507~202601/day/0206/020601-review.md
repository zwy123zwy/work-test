### 5. 手写 bind ❌

**评阅**：存在严重问题：
- 覆盖了原生 `Function.prototype.bind`
- 正确 API 应为 `fn.bind(thisArg, ...args)`，`this` 为 fn，不是第一个参数
- 未处理 `new` 构造场景（new 时 this 应指向实例）
- 正确写法应使用 `Function.prototype.myBind = function(thisArg, ...args) { const fn = this; ... }`

**测试用例**：

| # | 输入 | 期望输出 |
|---|------|----------|
| 1 | function f(a,b){return this.x+a+b}, {x:1}, 2 → bound(3) | 6 |
| 2 | 作为构造函数 new bound() 时，this 为实例 | 实例 |
| 3 | 无 thisArg 时传入 null/undefined | 非严格模式 global |

### 6. 手写 Promise ❌

**评阅**：主要问题：
- `constructor` 未调用 `executor(this.resolve.bind(this), this.reject.bind(this))`，Promise 永远不会 resolve/reject
- 无静态方法 `MyPromise.resolve`
- `then` 中 `resolveHandler`/`rejectHandler` 在 status 已变更时需异步调用（当前同步调用可能导致顺序问题）

**测试用例**：

| # | 输入 | 期望输出 |
|---|------|----------|
| 1 | new MyPromise(r=>r(1)).then(v=>v) | 1 |
| 2 | new MyPromise((_,r)=>r('err')).then(null,e=>e) | 'err' |
| 3 | MyPromise.resolve(2).then(v=>v) | 2 |
| 4 | then 链式返回值 | 正确传递 |
| 5 | then 中返回新 Promise | 等待该 Promise 完成 |

### 9. 有效的字母异位词 ❌

**评阅**：逻辑错误。同一轮中对 s[i] 做 `map.set(s[i], +1)` 后，`map.get(s[i])` 至少为 1，`> 0` 恒成立，导致直接 return false。正确做法：先统计 s 中各字符次数，再遍历 t 逐字符减 1，出现负值即非异位词。

|---|------|----------|
| 1 | 'anagram', 'nagaram' | true |
| 2 | 'rat', 'car' | false |

| 4 | '', '' | true |
| 5 | 'a', 'a' | true |

### 20. lodash get ❌

**评阅**：两处错误：
- 条件反了：`if (typeof obj === "object" && obj !== null) return defaultValue` 应在 obj 非对象时返回 default，应为 `if (obj == null || typeof obj !== 'object') return defaultValue`
- `if (obj[key])` 会在值为 0、false、'' 时误判，应改为 `if (!(key in obj)) return defaultValue` 或 `obj == null` 时返回 default

**测试用例**：

| # | 输入 | 期望输出 |
|---|------|----------|
| 1 | {a:{b:{c:3}}}, 'a.b.c' | 3 |
| 2 | {a:{b:{c:0}}}, 'a.b.c' | 0 |
| 3 | {a:{b:{c:false}}}, 'a.b.c' | false |
| 4 | {a:{}}, 'a.b.c', 'default' | 'default' |
| 5 | null, 'a', 'x' | 'x' |
| 6 | {}, 'a', 99 | 99 |
