- `3311.2`：`ReferenceError`。`let` 有暂时性死区。

- `3311.7`：`s p t`。微任务优先于宏任务。
- `3311.8`：`Promise.all`：下标回填 + 计数 + 任一失败即 reject。
- `3311.9`：不能。箭头函数 `this` 词法绑定。
- `3311.10`：AI 客服分流：意图识别+置信度阈值+人工兜底+埋点；AI 补充澄清问题策略。
- `3311.11`：`compose`：`reduceRight`。
- `3311.12`：`a.x` 是 `undefined`，`b.x` 是 `{ n: 2 }`。
- `3311.13`：`flat`：递归 `reduce`，`depth` 终止。
- `3311.14`：`var` 输出 `3,3,3`；`let` 输出 `0,1,2`。
- `3311.15`：AI 打字机：分批渲染（rAF/时间片）+ 接近底部自动滚动 + 用户上滑暂停。
- `3311.16`：`sleep(ms)`：`new Promise(r => setTimeout(r, ms))`。
- `3311.17`：JSON 深拷贝不完全可靠（函数/undefined/Symbol/循环引用/Date/Map/Set）。
- `3311.18`：`myNew`：建对象、连原型、执行构造器、按返回值规则返回。
- `3311.19`：`then` 抛错会进入后续 `catch`。
- `3311.20`：推荐理由展示：可解释字段 + 可信度 + 纠错入口；AI 补充风险词过滤与模板化理由。

## daily03312（1-20）
- `3312.1`：`useEffect([])` 挂载执行一次（严格模式开发可能双调用）。
- `3312.2`：`usePrevious`：`useRef` 存上次值，`useEffect` 更新。
- `3312.3`：`useDebouncedValue`：`state + effect + clearTimeout`。
- `3312.4`：同事件三次 `setN(n+1)` 通常结果 `+1`；函数式更新可 `+3`。
- `3312.5`：10w 会话性能：虚拟列表、分段渲染、懒加载；AI 补充语义折叠历史。
- `3312.6`：`createStore`：`getState/dispatch/subscribe`，dispatch 用快照通知。
- `3312.7`：`combineReducers`：遍历 reducer map 合并 `nextState`。
- `3312.8`：不推荐 index key：重排时状态错复用。
- `3312.9`：`useMemo` 不能单独阻止子组件重渲染，需 `React.memo` + 稳定引用。
- `3312.10`：模型切换降级：能力矩阵、超时熔断、自动回退；AI 补充按问题类型选模。
- `3312.11`：`useEvent`：`ref` 持有最新 fn + 稳定回调。
- `3312.12`：`useLocalStorage`：懒读本地 + effect 回写。
- `3312.13`：父更新子组件不一定重渲染（`React.memo` 可跳过）。
- `3312.14`：`useMount`：`useEffect(fn, [])`。
- `3312.15`：可信度展示：置信度/来源/复核按钮；AI 补充无来源风险标识。
- `3312.16`：`useWhyDidYouUpdate`：`prevProps` 对比打印差异。
- `3312.17`：Context 值变化会触发所有消费者更新（可拆分 context/selector 化）。
- `3312.18`：`useThrottleFn`：`ref` 存时间戳/timer，返回稳定函数。
- `3312.19`：StrictMode 双执行用于暴露副作用，不是生产行为。
- `3312.20`：自动补全防闪烁：锚点插入、请求去重、延迟展示、输入优先；AI 补充候选排序。
